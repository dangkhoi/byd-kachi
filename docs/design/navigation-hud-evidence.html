03

Design Decisions

Truthful status

EMITTING is set immediately before delivery invocation. Only an explicit matching sequence observation can set DISPLAY_VERIFIED.

Fault isolation

Blocking, exceptions, deadlines and saturation change only the owning adapter’s state. Older tasks cannot overwrite newer fault/verification truth.

Lifecycle

Per-output enable/disable calls one adapter. Whole-session Stop alone clears the session/store and independently stops both outputs.
