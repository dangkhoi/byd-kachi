08

Prioritized recommendations

Quarantine artifact pipeline

Trước mọi candidate:

  • Tạo vehicleTest riêng: release-key signed, debuggable=true.
  • release non-debuggable, fail nếu thiếu release key, lint abort.
  • Collector inspect APK thật: package/version/variant/signer/debug flag.
  • Metadata publish bằng temp + atomic replace.

Fix Cast safety model

Ưu tiên P0 crash path:

  • Closed target classification ở boundary; CastSlot không thể chứa protected.
  • Parser typed stack/task/windowing/bounds; ambiguity reject.
  • Bounded operation owner với connect/read/op deadlines và close-on-timeout.
  • Stop là priority/preemptive control, không xếp sau I/O.

Make postconditions authoritative

Mọi mutation phải trả typed outcome:

  • Cast exact task lands + exact bounds.
  • Return exact task absent/moved to expected stack.
  • Resize/density persist chỉ sau observed apply.
  • Failure giữ occupant/state/preferences trước đó.

Repair Navigation outputs

Không bọc thêm synthetic frame:

  • Giữ original session/source/sequence tới physical owner.
  • Một owner/queue/cache cho mỗi output; bỏ queue kép.
  • HAL writer trả sealed success/failure.
  • Clear fence old work, execute, ack/retry; dedup theo applied state.

Make widget slots truly independent

Tách domain model:

  • Mỗi slot có value/timestamp/freshness/reason/generation.
  • Parser không dùng combined gate.
  • Generation-bind HostView/listener; durable pending ID cleanup.
  • Speed clear là state machine retryable cho OFF/stale/disconnect/destroy/bootstrap.

Rebuild active tests before deleting legacy

Thay thế coverage, không chỉ xóa:

  • Owner clear ordering, HAL fail, saturation, wedge, retry.
  • Widget independent freshness + lifecycle + commit failure.
  • Cast real-dump ambiguity, CP/AA stack proof, split/return/resize failure matrix.
  • Bubble rapid tap/recreate/48dp/accessibility; simplified diagnostics.

Finish UI lifecycle and geometry

R8/R7 closure:

  • Retain/remove listeners; cancel/token all delayed work.
  • Single tap token and visible reject/coalesce.
  • Touch targets ≥48dp; disabled means non-destructive.
  • Display-aware editor; one global split DPI control.

Re-run gates in order

Chỉ chuyển T8 khi:

  • Fresh compile/tests + replacement coverage pass.
  • lintVehicleTest và lintRelease 0 errors.
  • 0 actionable P0–P3 after repeat review.
  • Security CLEAN + current exact-source 1.03 manifest.
