Context

Track A · Navigation + HUD

  • One authoritative navigation source/session.
  • One immutable frame/store and lifecycle owner.
  • Cluster-lane and HUD have independent bounded output adapters.
  • Whole-navigation Stop ends the shared session; output toggles remain local.
  • No GPS Dead Reckon dependency or mock-location target UX.

Track B · Cluster Cast

  • Durable V2 envelope, epoch, transaction ledger and stable baseline.
  • Observed, operation and stable states remain separate.
  • Single canonical versioned CastUiState and action derivation.
  • One compensation attempt; legacy active sessions are read-only.
  • Disconnected-sink recovery requires typed owner/session-loss truth, two stable samples, explicit consequence confirmation and one durable attempt; interaction context is diagnostic-only.
Working-tree reality: the large dirty tree predates this planning pass. Execution must preserve unrelated paths, avoid reset/clean/checkout/branch switch, and operate only inside owner-approved per-wave allowlists. Existing APKs are immutable evidence artifacts; they cannot be overwritten or relabelled as a new build.
Dead Reckon debt: independent closure review is explicitly deferred and non-blocking only while Dead Reckon remains REMOVE and untouched. It becomes blocking before DR removal implementation, mock-provider mutation, exact-two-runtime release evidence, public release claims or revival.

             + full tracked-diff SHA
             + intended untracked path/SHA set

             + toolchain/config/flags

Before any future wave changes a library/API/architecture choice, it must use Context7 official documentation to verify current version, non-deprecated API and alternatives, then record the result in the subordinate evidence ledger and the owning spec.
