ClusterNav · Cluster Cast enable toggle
Consolidated spec · requirements · design · tasks · off-car

Master switch để bật/tắt Cluster Cast — giữ lại nav lên cụm & HUD.

Một số người dùng chỉ muốn đưa dẫn đường lên cụm đồng hồ (và HUD), KHÔNG muốn tính năng chiếu app (Cast). Thêm một công tắc "Bật Cluster Cast" (mặc định BẬT) lưu bền: BẬT → mở chiếu + hiện nút nổi như cũ; TẮT → dọn cụm về đồng hồ gốc, không vẽ chiếu, không nút nổi, và ẩn luôn phần UI Cast bên phải cho gọn — mọi lần mở app sau vẫn giữ trạng thái đó. Nav→cụm và HUD là hai track độc lập nên KHÔNG bị ảnh hưởng. Gộp vào release candidate 1.05.

  • Bổ sung: khi disable, ẩn luôn phần UI Cast bên phải cho đẹp.

Design

Kiến trúc — một công tắc gate track Cast; nav & HUD đi đường riêng

quyết định / độc lập nhánh BẬT nhánh TẮT
Boundary (W5.3) — vì sao TẮT Cast không gãy nav/HUD: nav→cụm là broadcast Intent (ClusterBroadcaster, "KHÔNG chiếm màn"), không dùng projection. HUD/speed-sign (WazeHudSource) đọc logcat qua coordinator.executeShell — chỉ mượn cổng shell đặc quyền, không cần projection. Vì thế CastEnableSwitch.disable() chỉ closeProjection() + stop service, tuyệt đối không SimpleCastRuntime.shutdown() (huỷ singleton) — nếu huỷ, cổng shell mất và HUD gãy. Trace E2E: bật/tắt Cast → ClusterBroadcaster.emitLane vẫn phát; WazeHudSource{executeShell} vẫn chạy.

D1 — Pref master enable (R1)

Thêm vào interface SimpleCastPrefs (:core, thuần) fun castEnabled(): Boolean + fun setCastEnabled(enabled: Boolean). Impl SharedPrefsSimpleCastPrefs (app): getBoolean("cast_enabled", true) / putBoolean — cùng file simple_cast_prefs. FakePrefs (core test) thêm field default true. Mở interface ⇒ cập nhật ĐỒNG BỘ cả hai implementer (nếu thiếu → compile fail, đã kiểm: chỉ 2 implementer).

D2 — Gate 3 entry point (R2, R3)

Cast có đúng 3 chỗ khởi động projection/nút nổi — gate cả ba trên castEnabled:

  • MainActivity: bọc startForegroundService(FloatingBubbleService) trong if (…prefs.castEnabled()).
  • MainActivityCastController.onCreate: if (coordinator.prefs.castEnabled()) coordinator.openProjection(); onDestroy: chỉ closeProjection() khi castEnabled && !autostartOwns (không đóng thứ chưa mở).
  • FloatingBubbleService (đường boot/autostart — quan trọng nhất): thêm castEnabledNow() (getOrDefault(true) fail-safe). Trong onCreate và onStartCommand, gate đặt SAU startForegroundOnce() (giữ hợp đồng foreground-service: phải startForeground trong ~5s) và TRƯỚC requestOverlayIfMissing(): if (!castEnabledNow()) { stopSelf(); return }. Đứng hẳn ⇒ không showBubble, không dispatchBootAutoStart.
Thứ tự trong service (khoá bằng test): startForegroundOnce() → castEnabledNow() gate → requestOverlayIfMissing(). Giữ nguyên bất biến của FloatingBubbleFirstLaunchContractTest ("foreground trước overlay") — chỉ chèn gate vào giữa.

D3 — CastEnableSwitch (R4) + wiring

Class mới app/…/clustercast/CastEnableSwitch.kt (81 LOC), khuôn theo CastDeepRescueAction ("đứng hẳn, không mở lại", trừ force-stop DashCast vì đây là preference chứ không phải rescue xung đột):

fun bind(switch, castBody, disabledHint):
  switch.setOnCheckedChangeListener(null)   // tránh bắn khi set trạng thái đã lưu
  switch.isChecked = prefs.castEnabled()
  applyVisibility(enabled, castBody, disabledHint)
  switch.onCheckedChange { isChecked ->
    prefs.setCastEnabled(isChecked)
    applyVisibility(...)
    if (isChecked) enable() else disable()
  }
enable():  openProjection(); startForegroundService(FloatingBubbleService); toast
disable(): dispatch(Stop()); closeProjection(); stopService(FloatingBubbleService); toast  // NO reopen

Wire trong MainActivityCastController.onCreate: CastEnableSwitch(activity, coordinator).bind(findViewById(switch_cast_enabled), findViewById(cast_body), findViewById(txt_cast_disabled_hint)). openProjection/closeProjection/dispatch tự queue trên serial-executor của coordinator ⇒ shell chạy ngoài UI thread.

D4 — Layout: header switch + cast_body thu gọn (R5)

Cả layout/ lẫn layout-w960dp/: đổi title "Cluster Cast" thành header row (TextView weight=1 + Switch switch_cast_enabled) — song song với thẻ "Navigation + HUD". Thêm txt_cast_disabled_hint (gone mặc định, hiện khi tắt: "Đang tắt · cụm vẫn hiện dẫn đường và HUD như thường…"). Bọc toàn bộ nội dung Cast (subtitle → recovery) trong LinearLayout id=cast_body. btn_check_update chuyển RA NGOÀI cast_body (xuống đáy thẻ) để vẫn bấm được khi Cast tắt. Khi tắt: cast_body GONE ⇒ cột phải (màn xe) thu còn header + hint + nút cập nhật = "gọn/đẹp".

Autonomous decisions (ghi lại): (1) Dùng Switch (không CheckBox) để đồng bộ với thẻ Navigation+HUD (switch_enabled) — cùng ngữ nghĩa master on/off. (2) Ẩn = thu cast_body về header + hint (giữ switch để bật lại) thay vì xoá cả cột phải + dời switch sang trái — discoverable hơn, không lệch layout weight. (3) btn_check_update giữ hiển thị (cập nhật app không thuộc Cast) → đặt ngoài cast_body, xuống đáy thẻ.
Implemented (2026-08-11): tất cả D1–D4 đã code + build + test xanh (xem §Tasks / §Verification). Open Questions

wm reset khi tắt?

disable() dùng closeProjection() (chuẩn "trả cụm về đồng hồ", giống nút clear-cluster). KHÔNG thêm wm size/density/overscan reset như deep-rescue (đó là cho ca xung đột DashCast). Nếu on-car thấy sót state VD sau khi tắt, cân nhắc thêm reset — ghi nhận, chưa làm (tránh over-engineering).

Switch vs Checkbox

Owner nói "checkbox"; đã chọn Switch cho đồng bộ với thẻ Navigation+HUD. Cùng ngữ nghĩa on/off. Nếu owner muốn đúng checkbox, đổi 1 dòng layout (id giữ nguyên).
