Level 2 nâng gì so Level 1: nền cockpit tối (đẹp + đỡ chói ban đêm) · icon SVG nét đồng bộ thay emoji · hero trạng-thái-sống (mũi tên rẽ + cự ly + tốc độ + preview cụm) · thành phần chữ ký: ghế = sơ đồ xe nhìn-từ-trên (chạm ghế để chỉnh, sáng theo mát/sưởi), bụi = đồng-hồ-đo · gradient + chiều sâu (bóng, viền sáng) · switch phát sáng.
Chọn: Level 1 (iOS-Settings, sáng, an toàn/nhanh) hay Level 2 (Cockpit tối, mỹ thuật cao hơn)? Lưu ý L2 công nhiều hơn (SVG icon set + component chữ ký ghế/gauge + theme tối), nhưng vẫn giữ nguyên feature/@+id/logic — chỉ là style + vài custom view. Có thể pha: lấy theme tối + icon + hero của L2, giữ độ đơn giản của L1.
