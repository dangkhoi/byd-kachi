3. Requirements

Chức năng

  • R1 — Một chủ dadb. Đúng 1 ShellTransport sở hữu kết nối localhost:5555 cho mọi lệnh cửa sổ/display; gom 3 đường cũ (grep xác nhận 3→1). Mọi lệnh nối tiếp qua nó.
  • R2 — Command model + cổng chủ quyền. WindowMutation (sealed) đi qua WindowCommandDispatcher được validate bởi DisplayOwnershipRegistry: launcher = display 0 + VD của nó; cast = display 1; launcher CẤM chạm display ≥ 1 (reject + log).
  • R3 — Single-writer state bền. FreeformSeedPolicy là nơi DUY NHẤT ghi enable_freeform_support/force_resizable_activities/wm size/wm density; marker commit()-trước-mutate; FF_USER_REMOVED terminal; reset = clearer duy nhất.
  • R4 — Ưu tiên STOP. Hàng đợi cửa sổ giữ semantics BoundedCastExecutor: STOP/RESCUE ▸ NORMAL (KHÔNG hạ về FIFO — để STOP không kẹt sau lệnh treo).
  • R5 — Chạm đường riêng. Input daemon (socket localabstract, injectInputEvent) + fallback input -d; chạm KHÔNG đi qua hàng đợi lệnh, chỉ lifecycle daemon qua hàng đợi.
  • R6 — UDF + ViewModel. HomeViewModel giữ StateFlow<HomeUiState> là nguồn sự thật; WorkspaceView hết giữ state (view thuần render+callback); Activity mỏng, collect repeatOnLifecycle(STARTED).
  • R7 — Manual-DI. Một AppContainer (object graph) gộp SimpleCastRuntime (by-reference); viewModelFactory; KHÔNG Hilt/Koin.
  • R8 — Auto-start. Foreground service mount ô đã lưu lúc boot (idempotent + in-flight + cooldown); HOME giữ trivial renderer; KHÔNG auto-start app mà cast đang chiếu (hỏi AppLocationRegistry).
  • R9 — Coexistence cluster-cast = 4 luật (R1 transport + R2 cổng chủ quyền + R3 single-writer + trọng tài task) — xem §4.4.

Phi chức năng

  • R-nf1. Byte-stable mọi chuỗi lệnh shell đã proven (chốt bằng golden test ở B0; refactor sau giữ y).
  • R-nf2. :core THUẦN JVM (không android.*) — LayeringRulesTest (pureFilesStillInApp == 0) + CoreIsolationTest xanh.
  • R-nf3. 0 file logic cast bị đụng (cast KHÔNG E2E-verify được off-car); chỉ CastShell freeform-seed delegate byte-identical.
  • R-nf4. Giữ máy build/chạy sau mỗi stage; file ≤ 500 LOC; degrade-safe (fail dadb không treo/không crash).

4.6 Quyết định thiết kế + Context7 (W1)

  • ShellTransport = MECHANISM, dispatcher = POLICY. Transport chỉ dispatch thô + serialize; validate ownership + ưu tiên nằm TRÊN. Seam (String)->String giữ nguyên nên caller cũ byte-identical.
  • PrioritySerialExecutor đặt ở :core (THUẦN) vì LayeringRulesTest.pureFilesStillInApp == 0 cấm file thuần trong :app; ShellTransport (:app) delegate xuống. exec/run(cmd, priority = NORMAL) ⇒ mọi caller cũ byte/behaviour-identical.
  • Cast fold BY REFERENCE. AppContainer.castRuntime get() = SimpleCastRuntime — trả object process-singleton hiện có, KHÔNG dựng/không sở hữu coordinator, KHÔNG rewire caller cast (an toàn: cast không E2E-verify được off-car).
  • Giữ android.app.Activity (KHÔNG migrate ComponentActivity để tránh dep mới); cho nó làm ViewModelStoreOwner + lấy VM qua ViewModelProvider(this, factory) (chỉ androidx.lifecycle). configChanges đã chặn recreate ⇒ không lo config-survival.
  • Input daemon scrcpy-style (không build jar riêng): app_process nạp class từ APK CLASSPATH; InputManager.injectInputEvent qua reflection (getInstance() ≤12 / InputManagerGlobal 13+) + MotionEvent.setDisplayId.
  • Context7 verify (2026-09-09): kotlinx-coroutines 1.10.2 (-android + -test) · androidx.lifecycle 2.9.0 (viewmodel-ktx + runtime-ktx → viewModelScope/repeatOnLifecycle) · Turbine 1.2.1 (testImpl). API hiện hành, KHÔNG deprecated: MutableStateFlow+asStateFlow(), _state.update{}/updateAndGet{}, runTest{}, Turbine.test{ awaitItem() }.

  • Sai lệch spec (có chủ ý) — auto-start service KHÔNG mount VD. Plan (B6) ngụ ý service mount ô, nhưng VD backed bởi SurfaceView Activity ⇒ service headless bất khả. Đổi: service lo surface-independent (seed/set-HOME/plan) + đảm bảo HOME lên → Activity restore+mount. Ghi rõ ở arch-stage-6-done.md.
  • Sai lệch spec — KHÔNG migrate ComponentActivity. Plan gợi ý by viewModels(), nhưng :app không có androidx.activity ⇒ thêm = dep mới (vi phạm "no new external dependency"). Đổi: giữ android.app.Activity làm ViewModelStoreOwner, lấy VM qua ViewModelProvider (chỉ androidx.lifecycle).
  • Sai lệch spec — SlotCommands (glue intent thuần) KHÔNG tách được ra file riêng. LayeringRules chặn (file thuần phải ở :core, mà nó nối type :app) ⇒ giữ glue trong composition-root (Activity), tách VIEW-SETUP (chạm android) thay thế.
  • Quyết định — cast fold BY REFERENCE. Cast không E2E-verify được off-car ⇒ AppContainer.castRuntime lộ singleton SimpleCastRuntime hiện có, KHÔNG rewire caller/logic. Kết quả: 0 file modules/clustercast/ bị đụng (git xác nhận).
