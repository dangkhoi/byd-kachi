4Design

4.1 Matcher (:core) — bỏ gesture R1

VoiceKeyMatcher: xoá enum VoiceKeyGesture, nhánh PRESS/HOLD, hằng DEFAULT_LONG_PRESS_MS. Logic mới: nếu keyCode == cfg.keyCode → consume=true ở DOWN/UP/OTHER; fire=true đúng 1 lần mỗi lần nhấn (khoá theo downTime, bắn trên UP; nếu chỉ có DOWN thì bắn trên DOWN). Không phụ thuộc thời gian giữ → hết nghi phạm #3. VoiceKeyConfig bỏ field gesture. Cập nhật VoiceKeyMatcherTest.

4.2 Đích = package (bỏ enum trợ lý) R4

Bỏ enum VoiceKeyTarget khỏi luồng chính. Đích lưu dạng String: hoặc package name, hoặc 1 trong 2 sentinel ghim đầu (__ASSIST__, __RECOGNIZER__). AssistantLauncher → AppLauncher.launch(ctx, spec):

when (spec) {
  "__ASSIST__"     -> ACTION_ASSIST / VOICE_COMMAND (trợ lý mặc định hệ thống)
  "__RECOGNIZER__" -> RecognizerIntent.ACTION_VOICE_SEARCH_HANDS_FREE / WEB_SEARCH
  else /* package */ -> pm.getLaunchIntentForPackage(spec)  // mở THẲNG app, +FLAG_ACTIVITY_NEW_TASK
                        ?: Intent(ACTION_MAIN).addCategory(LAUNCHER).setPackage(spec)
}

Chọn app trực tiếp = không còn đoán intent ASSIST → không lạc Gemini. (Kiki = chọn app ai.zalo.kiki.car → getLaunchIntentForPackage → CarMainActivity.)
