3. Chọn: #1 + #10 + #8 (ASR-cửa-sổ fuzzy "kachi", có RMS gate + biến thể "ơi")

Đơn giản nhất, KHÔNG train, KHÔNG model mới, tái dùng đúng model NGHE đã hiểu "kachi". Luồng:

  1. Mic nền (đã có VoiceWakeListener) → RMS gate (đã có) lọc im lặng.
  2. Có tiếng ⇒ gom cửa sổ PCM ~1.5s → chạy model NGHE hiện tại (OfflineRecognizer, cùng model command) → text.
  3. Fuzzy-match "kachi" ở BẤT KỲ vị trí trong text (dùng VoicePhoneticConfusions + tập biến thể: kachi·ca chi·ka chi·ga chi·co chi·ka chi·gà chi·kachi ơi·ok kachi). Khớp ⇒ nổ wake → mở phiên lệnh (đường proven).
  4. Cửa sổ trượt (overlap ~0.5s) để không cắt giữa "ka|chi".

CPU: ASR nặng hơn KWS, nhưng: RMS gate + duty-cycle (chỉ decode khi có tiếng) + VoiceLoadGuard (suspend khi load cao) đã có. Model int8 (~74MB) decode 1.5s window nhanh (RTF ~0.01–0.1). Đo baseline trên xe.
