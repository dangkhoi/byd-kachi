TRACK 2 — Debug: máy dò nav sạch (nhánh riêng, cài song song)

Requirements

IDYêu cầuP
RT2.1Mỗi phiên = file MỚI — KHÔNG tái dùng file cũ. Sửa gốc "log lẫn lộn": file gắn theo (versionName + boot-session-id); khác → tạo file mới. Header ghi session-id + thời điểm + lý do bật.P0
RT2.2Mỗi bản ghi kèm context: app đang foreground + danh sách nav-app đang chạy tại thời điểm capture → quy kết nguồn đáng tin.P1
RT2.3Cố lấy sender package của broadcast nav (AUTONAVI/NAVIGATION_STATE) — biết đích xác app nào phát.P1
RT2.4Export ra external files dir (adb-pullable) — bỏ rào file nội bộ (bản debug, không lo PII vì chỉ mình dùng).P1
RT2.5Isolation test mode: nút "đo 1 app" → force-stop nav khác + ghi rõ chỉ-1-nguồn.P2
RT2.6Debug build = applicationId riêng (.debug), label "ClusterNav DEBUG", versionName có hậu tố -debug → cài SONG SONG bản release, log không bao giờ lẫn.P1

Design

  • Sửa NavProbe.file(): thêm K_SESSION = versionName + ":" + bootId (Settings.Global boot_count hoặc elapsedRealtime mốc). Khác session → newFilePath(), không reuse. → hết trộn cũ/mới.
  • recordBroadcast/recordNotification/recordNodes: prepend 1 dòng context (fg=<pkg> · nav=[đang chạy]).
  • Sender pkg: dùng dynamic receiver + getSentFromPackage() nếu API cho, hoặc log-correlation; best-effort, ghi "?" nếu không lấy được.
  • Export: bản debug ghi getExternalFilesDir()/navprobe/ (thay filesDir) → adb pull thẳng. Bản release giữ nội bộ (privacy).
  • Build variant: debug flavor trong build.gradle.kts — applicationIdSuffix ".debug", versionNameSuffix "-debug", label riêng. Ký cùng key nhóm.

Tasks (DAG)

  • T2.a — Nhánh debug/navprobe-clean off main. Thêm build variant .debug (applicationId riêng, label, versionName suffix).
  • T2.b — Sửa NavProbe.file() session-key (fix reuse) + header session-id. Test off-device.
  • T2.c — Per-record context + sender pkg + export external (debug flavor).
  • T2.d — Isolation test mode (nút đo-1-app). Senior review. Build debug APK.
  • T2.e — (khi có xe) cài song song release, dò lại sạch → kết luận nguồn AUTONAVI/nav CP-AA.
