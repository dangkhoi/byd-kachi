  • :core ShortcutGridFit.fit(n, w, h, gapRatio, minIcon, maxIcon) — thuần, đơn vị px: thử mọi số cột c = 1…n, hàng r = ⌈n/c⌉; cỡ icon s lớn nhất sao cho c·s + (c+1)·g ≤ w và r·s + (r+1)·g ≤ h với khe g = gapRatio·s; chọn c cho s lớn nhất (hoà thì ít hàng trống hơn).
