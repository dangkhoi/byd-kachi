2. Context

Bot Telegram (spec kachi-telegram-remote) đã điều khiển được xe bằng lệnh gõ tay (/go, /play, /ac…). Vấn đề owner nêu: nhớ từng lệnh khó, nhất là khi đã chỉnh nhiều thứ trên xe. Wave này bọc mọi việc hay dùng bằng NÚT BẤM phân cấp + đăng ký gợi ý lệnh (setMyCommands), và thêm điều khiển nhạc đang phát (play/pause/next) — thiếu hụt lớn nhất cho ca "ngồi sau điều khiển nhạc không phiền tài xế".

Nền sẵn có (đã [ĐO] đọc code):

  • TelegramInlineKeyboard (:core) — đã dựng placesKeyboard + HELP; tự ghép JSON, không org.json.
  • TelegramBridgeService (:app) — FGS polling 60s, execute() thi hành lệnh, đã xử callback navi:<index>.
  • MediaBridge (:app) — play/pause/next/prev qua MediaController.TransportControls + read(): MediaSnapshot(title, artist, playing, …). Transport khả thi, không phải viết lại.
  • ControlRegistry + VoiceControlDispatch — lệnh xe tuyệt đối (set-to-X) đã có; cổng tốc độ (cốp/kính/nóc) qua CtlSafetyPolicy.
  • WorkspacePrefs.savedPlaces() — sổ địa chỉ dùng chung; voiceMusicDefaultApp / voiceNavDefaultApp.

Ràng buộc Telegram: callback_data ≤ 64 byte; inline keyboard xếp hàng (≤4 nút/hàng cho dễ bấm); answerCallbackQuery phải trả <1s; editMessageText/editMessageReplyMarkup để sửa bảng tại chỗ; setMyCommands đăng ký gợi ý lệnh.

4. Design

4.1 Kiến trúc — tách core (thuần) ↔ app (Android)

Nguyên tắc như spec gốc: :core dựng CHUỖI JSON của keyboard + phân giải callback (thuần, test off-car); :app gọi Telegram API + đọc trạng thái xe/nhạc + thi hành. KHÔNG mở đường ghi thứ hai — lệnh xe vẫn qua VoiceControlDispatch (cổng tốc độ), nhạc qua MediaBridge, dẫn đường qua PendingNavStore/ScheduledNavApplier đã có.

  • :core mới: TelegramMenu (dựng JSON mọi bảng: menu chính, điều hoà, ghế, nhạc, khác, dẫn đường, xác nhận) · TelegramCallback (data class + parse/encode v<nonce>:<domain>:<action>:<id>) · TelegramStatusLine (ghép text trạng thái sống từ snapshot thuần). Mở rộng TelegramInlineKeyboard hiện có.
  • :app mới/sửa: TelegramApi += answerCallbackQuery, editMessageText, editMessageReplyMarkup, setMyCommands, deleteMessage · TelegramBridgeService.handleCallback() (phân giải → thi hành → sửa bảng) · đọc trạng thái xe qua freshCar/ControlRegistry.readState + nhạc qua MediaBridge.read().
