Cluster Cast: Projection-First, Move-App, Done.

Bỏ state machine phức tạp, bootstrap verification, seal tracking và migration. Thay bằng: mở projection một lần → cast = di chuyển app sang display 1 → stop = di chuyển app về display 0. Projection vẫn mở, cụm luôn sẵn sàng. Config wm size + wm overscan riêng từng loại app.

Context

Field-proven 2026-08-02: Toàn bộ recipe cast/stop cho app thường, CarPlay và Android Auto đã được kiểm chứng trên xe thật. Cast thành công 3-4s, Stop 1-2s, cast lặp lại nhiều lần OK.

Vấn đề của kiến trúc cũ

  • Verification luôn fail — observation race với migration refresh, completeVerificationLocked ghim RECOVERING vĩnh viễn
  • Projection đóng do reset seal — resetSessionForFreshBoot xoá seal → cast không bootstrap
  • State machine 11 trạng thái — ObservedState (6) + OperationState (6) + StableState (5) → quá phức tạp cho use case đơn giản
  • SCALE_CLUSTER_DENSITY gây hỏng — density global ảnh hưởng mọi app, không reset khi crash
  • UI chậm 10-15s — reconcile cycle + observation timeout → trạng thái không phản ánh thực tế

Hướng mới (owner-approved)

  • Projection mở khi app khởi động — user mở ClusterNav = cụm sẵn sàng ngay, không cần bấm thêm

  • Stop = bấm bất kỳ nút nào — khi đang chiếu, mọi tap trên bubble = trả app về display 0
  • Tắt app = đóng projection — profile 18/0, cụm về đồng hồ
  • Per-app config — wm size + wm overscan theo từng loại app (CP/AA/thường)

4.1 Simplified state model — 4 trạng thái

IDLE = sẵn sàng castCASTING_FULL = CP/AA hoặc 1 app fullCASTING_SPLIT = 2 app thường chia đôiclose = đóng projection
CP/AA vs App thường: CP/AA chỉ có thể vào CASTING_FULL (chiếm toàn bộ cụm). App thường có thể vào CASTING_FULL (1 app full) hoặc CASTING_SPLIT (2 app chia đôi trái/phải). Từ CASTING_SPLIT, stop 1 slot → vẫn ở CASTING_SPLIT (1 slot trống), stop cả 2 → IDLE.

4.5 Projection lifecycle

// Open projection (OFF → IDLE) — called automatically on app onCreate
fun openProjection(displayId: Int, appType: AppType) {
    shell("service call SurfaceFlinger 1035 i32 $displayId i32 30")  // curved
    sleep(300)
    shell("service call SurfaceFlinger 1035 i32 $displayId i32 16")  // keepKmh  
    sleep(300)
    shell("service call SurfaceFlinger 1035 i32 $displayId i32 35")  // activate
    sleep(500)
    applyDisplayConfig(displayId, appType)
    state = IDLE
}

// Close projection (→ OFF)
fun closeProjection(displayId: Int) {
    shell("service call SurfaceFlinger 1035 i32 $displayId i32 18")  // close
    sleep(300)
    shell("service call SurfaceFlinger 1035 i32 $displayId i32 0")   // refresh
    state = OFF
}

// Cast app (IDLE → CASTING) — always FULL cluster for CP/AA
fun castApp(pkg: String, displayId: Int) {
    val appType = classifyApp(pkg)
    if (currentDisplayConfig != appType) applyDisplayConfig(displayId, appType)
    when (appType) {
        CP, AA -> shell("am stack move-task $taskId $stackOnDisplay1")  // full only, no split
        NORMAL -> shell("am start --display $displayId --windowingMode 5 -n $pkg/$activity")
    }
    state = CASTING(target = pkg)
}

// Stop (CASTING → IDLE) — ANY bubble tap while casting = stop
fun stopCast(displayId: Int) {
    val target = state.target
    when (classifyApp(target)) {
        CP, AA -> shell("am stack move-task $taskId $stackOnDisplay0")
        NORMAL -> shell("am start --display 0 -n $target/$activity")
    }
    state = IDLE
}

4.6 Error handling — simple and fail-safe

Shell command fails

  • Retry once after 1s
  • If still fails: state stays at previous known-good state
  • Show toast "Lệnh thất bại, thử lại" — user bấm lại
  • NO automatic recovery chain, NO state machine escalation

App crashes on cluster

  • Detect via simple AM observation (optional, periodic 5s poll)
  • If active target gone from display 1: state → IDLE
  • Projection stays open — user can cast again immediately
  • NO complex orphan/residue tracking

4.7 UI state contract

// Replaces complex CastUiStateV2 with 19 recovery mappings
sealed interface SimpleCastState {
    object Off : SimpleCastState
    object Opening : SimpleCastState          // transient: projection opening
    object Idle : SimpleCastState             // projection open, ready
    data class CastingFull(
        val targetPkg: String,
        val appType: AppType,                 // CP | AA | NORMAL
        val displayConfig: DisplayConfig,
    ) : SimpleCastState
    data class CastingSplit(
        val left: SlotState?,                 // null = slot empty
        val right: SlotState?,                // null = slot empty
    ) : SimpleCastState
    object Stopping : SimpleCastState         // transient: returning app
    data class Error(val msg: String) : SimpleCastState  // show toast, auto-clear
}

data class SlotState(
    val pkg: String,
    val displayConfig: DisplayConfig,
)

enum class AppType { CARPLAY, ANDROID_AUTO, NORMAL }

data class DisplayConfig(
    val wmSize: String,      // e.g. "1422x800"  
    val overscan: String,    // e.g. "10,-120,10,50"
    val resizable: Boolean,
)

  • Classify app type từ package name
  • FakeShell tests cho mọi app type

Thay thế wiring cũ (CastFacade → CastCoordinator phức tạp) bằng SimpleCastCoordinator. Bubble tap: if CASTING → stop, if IDLE → cast foreground app.

Thay thế CastSessionStore + CastSessionEnvelope phức tạp. Chỉ lưu: last active target, per-app display config, automation config.
