  • AmapEmissionArbiter sole content sender.
  • HudMirrorController gates only.

  • Road remains separate capability.

Speed sign lifecycle

  • SpeedLimitFrame pure core model.
  • Exact files: NavNotificationListener.kt, WazeHudSource.kt, speed-source preference/arbiter and both sign ports.
  • Parameterized for WAZE and VIETMAP: positive→0, exact monotonic TTL=5,000ms expiry, source switch, listener/provider disconnect, source stop, master/output OFF, process epoch restart and queue saturation.
  • Each recording cluster/HUD port receives exactly one typed clear intent; no older-generation positive may follow. T0–T9 never translate clear intent into a property write.
  • Cluster/HUD ports independent; clear only after channel-specific proof.
