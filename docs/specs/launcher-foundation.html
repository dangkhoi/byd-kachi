Foundation spec — fork ClusterNav 2.0 → launcher xe BYD DiLink. Cập nhật 2026-09-08.

Trạng thái: Historical · Cập nhật: 2026-09-08 · Mục đích: foundation spec — fork ClusterNav 2.0 thành launcher (màn hình chính) cho xe BYD DiLink.

TL;DR. byd-launcher là bản fork của ClusterNav 2.0 (byd-cluster-2) để dựng thành một launcher (màn hình chính) cho xe BYD. Nó giữ nguyên toàn bộ tính năng ClusterNav (gom vào mục Cài đặt / Settings), thêm vỏ HOME và nhiều app/tiện ích đi kèm kiểu Dudu桌面. Cài song song (applicationId = com.byd.launcher) nên bản ClusterNav 2.0 ổn định (com.byd.clusternav2) trên xe không bị đụng.

2. Context — vì sao fork

ClusterNav 2.0 (byd-cluster-2) đã ổn định (v1.38, đang chạy tốt trên xe owner) — owner chốt "để im". Owner muốn một launcher riêng, mà bản chất launcher chỉ value khi đi kèm nhiều app/tính năng (Dudu桌面PRO có rất nhiều). Vì launcher phải giữ nguyên mọi chức năng ClusterNav, fork nguyên codebase là đúng (không bê từng phần). Nền HAL/shell của ClusterNav (BydHal reflection + carexec/dadb đặc quyền) chính là thứ Dudu dùng (tầng "shellManage") — tái dùng được ngay.

Quyết định fork

  • applicationId com.byd.clusternav2 → com.byd.launcher (cài song song). Namespace code com.byd.clusternav.* GIỮ NGUYÊN (không rename hàng loạt — chỉ 1 dòng build.gradle).
  • OTA UpdateChecker.REPO → dangkhoi/byd-launcher (khỏi kéo APK ClusterNav về launcher).
  • git init sạch (không mang ~38 APK nặng trong history byd-cluster-2). Fork từ working tree v1.38.
  • HAL cho control xe: theo RE Dudu, chuyển dần sang AbsBYDAutoDevice.set(featureId, i2, i3) cho phần mới (đèn/gạt/kính-%/sạc); giữ named-method cho cái đã proven (ghế/kính/PM2.5). Hybrid.

6. Open Questions / nợ RE

Từ docs/diagnostics/dudu-launcher-hal-RE-2026-09-06.md:
  • OQ1. Giá trị SỐ của BYDAutoFeatureIds.* — Dudu chỉ import tên. Cần pull /system/framework/*bydauto*.jar từ xe (hoặc OpenBYD apk đủ).
  • OQ2. Ngữ nghĩa arg set(featureId, i2, i3) cho window-%, wiper-overhaul, light — đọc lớp control Dudu (obfuscated).
  • OQ3. Tầng shellManage đặc quyền của Dudu — ClusterNav đã có dadb; có feature nào cần cơ chế khác không (nhiều feature set trực tiếp đã rc=0).
  • OQ4. Launcher cần khoá ký riêng + OTA channel riêng (hiện release build cần keystore.properties — chưa thiết lập cho fork; debug build OK).
  • OQ5. Đổi strings.xml (tên app) đang vướng seal T11 kế thừa từ ClusterNav — gỡ dần seal/baggage không liên quan launcher.
