Design

Phần 1 — HAL helper (module dex mới)

  • hal-helper/: class thuần Java/Kotlin KachiHalMain.main(port) — register AbsBYDAutoLightListener (reflection, tránh compile-dep runtime class), onLightOn(type)/onLightOff(type) (4=trái,5=phải) → ServerSocket, mỗi client nhận dòng JSON {"topic":"light.onLightOn","type":4}\n.
  • Build thành dex (d8) → đóng app/src/main/assets/kachi_hal.dex (hoặc .jar CLASSPATH).
  • HalHelperLauncher.kt (:app): copy asset → push /data/local/tmp/kachi_hal.jar qua dadb (Dadb.push) → chạy CLASSPATH=... app_process / com.byd.clusternav.hal.KachiHalMain 19322 qua ShellTransport (đúng lệnh kinex). Idempotent: nếu socket đã mở thì bỏ qua.

Phần 2 — Socket client

  • HalSignalClient.kt (:app): thread nối 127.0.0.1:19322, đọc dòng JSON, callback onTurn(left,right). Reconnect backoff. Realtime.

Phần 3 — Controller

  • Bỏ TurnSignalListener. CameraSignalController khởi HalHelperLauncher.ensure() + HalSignalClient khi bật camera; nhận onTurn → tick(left,right) (giữ HOLD chống nháy). Bỏ nhánh opt.

Phần 4 — Overlay (UI mới)

  • CameraOverlayView: cỡ nhỏ (~30% rộng × ~26% cao), bo góc tròn (radius khung launcher), đặt góc TRÊN (dưới header ~header height + margin). Góc = pref camera_pos_left/camera_pos_right ∈ {TL, TR}, default trái=TL/phải=TR. Có offset chỉnh.
  • R7 (2026-09-26) show(…, rotationDeg: Int = 0) → applyTransform(tv, vw, vh, crop, rotationDeg). Gọi ở CẢ onSurfaceTextureAvailable và SizeChanged. Controller truyền CameraSignalPolicy.rotationDegrees(Prefs.cameraRotation(appCtx), turn), log có rot=.
  • R7 · review Pass 1 (2026-09-26) — phép toán ma trận dời sang :core CameraOverlayTransform.matrix(vw, vh, crop, rotationDeg) trả 9 số row-major (hoặc null = khỏi transform); :app chỉ còn Matrix().apply { setValues(…) } + setTransform. Ba bước: (1) crop y như trước R7 scale(1/cw,1/ch) + dịch (−x0·sx·vw, −y0·sy·vh); (2) xoay quanh tâm view; (3) chỉ khi góc = 90/270 và khung không vuông: scale(vw/vh, vh/vw) quanh tâm ⇒ vùng crop phủ ĐÚNG vw×vh. Vì sao dời: android.graphics.Matrix là stub trên JVM ⇒ công thức trước đó không có bài test nào; nay CameraOverlayTransformTest chứng minh bằng số (map 4 góc crop, đòi rơi đúng 4 góc view) cho khung vuông và 400×300 / 300×400 / 1920×720.
