R1 — Track T3: Speed-limit badge overlay trên cluster display 1

User story: "Lái xe, tôi muốn thấy biển giới hạn tốc độ (nguồn VietMap) luôn hiện trên cụm đồng hồ, kể cả khi đang cast app khác, để biết mình đang ở mức nào mà không nhìn điện thoại."

User story: "Tôi muốn khi VietMap có biển 60, app TỰ ĐẨY giá trị 60 vào HAL để cụm OEM vẽ biển native (đẹp hơn overlay) — NẾU chứng minh được trên xe."

  • KHÔNG hardcode fallback candidate khác (0x4B4000AA, 0x23A00010) — mỗi candidate cần on-car evidence riêng trước khi wire

Approach: WindowManager overlay trên display context

// Trong FloatingBubbleService (đã chạy, đã có SYSTEM_ALERT_WINDOW)
val displayManager = getSystemService(DisplayManager::class.java)
val clusterDisplay = displayManager.getDisplay(clusterDisplayId) // 1
val displayContext = createDisplayContext(clusterDisplay)

val params = WindowManager.LayoutParams(
    badgeSize, badgeSize,
    WindowManager.LayoutParams.TYPE_APPLICATION_OVERLAY,
    WindowManager.LayoutParams.FLAG_NOT_FOCUSABLE or
        WindowManager.LayoutParams.FLAG_NOT_TOUCHABLE or
        WindowManager.LayoutParams.FLAG_LAYOUT_NO_LIMITS,
    PixelFormat.TRANSLUCENT
).apply {
    gravity = Gravity.TOP or Gravity.END
    x = 40; y = 40
}
wm.addView(speedBadgeView, params)

Lý do chọn overlay thay vì activity:

  • Overlay luôn đè mọi activity (z-order cao nhất) → đè cast app
  • ClusterNavActivity là fullscreen activity → DƯỚI overlay → không che badge
  • Không cần activity lifecycle riêng, không đụng task stack display 1
  • Đã có SYSTEM_ALERT_WINDOW trong manifest (line 14)
  • FloatingBubbleService đã chạy trên display 0 — extend thêm 1 view trên display 1

Ẩn số z-order (on-car confirm): Android 10 (DiLink3) có thể không cho overlay trên display ≠ 0 từ app uid. Nếu fail → fallback: vẽ badge ngay trong ClusterNavActivity layout (thêm ImageView + TextView góc phải) — nhưng badge sẽ biến khi cast (activity bị đè). Kết quả on-car quyết định dùng approach nào.

3.2 T1 — HalSpeedSignPort

Interface đã có

interface SpeedSignPort : AutoCloseable {
    val output: SpeedSignOutput
    fun publish(frame: SpeedLimitFrame, generation: Long): SpeedSignSubmission
    fun replaceWithClear(frame: SpeedLimitFrame, generation: Long): SpeedSignSubmission
}

Implementation

class HalSpeedSignPort(
    private val hal: BydHal,       // object, nhưng inject cho testable
    private val featureId: Int,    // 0x4B40001C resolved at init
    private val device: Any,       // BYDAutoStatisticDevice instance
) : SpeedSignPort {
    override val output = SpeedSignOutput.CLUSTER
    private val lock = Any()
    private var acceptedGeneration = 0L

    override fun publish(frame: SpeedLimitFrame, generation: Long): SpeedSignSubmission {
        synchronized(lock) {
            if (generation < acceptedGeneration) return SpeedSignSubmission.STALE_DROPPED
            acceptedGeneration = generation
        }
        // Ghi HAL — fire-and-forget (HAL write ~2ms, không block)
        BydHal.setInt(device, featureId, frame.value!!)
        return SpeedSignSubmission.ACCEPTED
    }

    override fun replaceWithClear(frame: SpeedLimitFrame, generation: Long): SpeedSignSubmission {
        synchronized(lock) {
            if (generation < acceptedGeneration) return SpeedSignSubmission.STALE_DROPPED
            acceptedGeneration = generation
        }
        BydHal.setInt(device, featureId, 0) // 0 = clear (unproven — cần on-car)
        return SpeedSignSubmission.ACCEPTED
    }

    override fun close() { /* HAL device has no close */ }

    companion object {
        /** Trả null nếu HAL không có feature này trên ROM → caller dùng Noop. */
        fun createOrNull(context: Context): HalSpeedSignPort? {
            val id = BydHal.featureId("STATISTICS_ISA_CURRENT_ROAD_SPEED_LIMIT_SET") ?: return null
            val ctx = BydHal.bypass(context)
            val dev = BydHal.device(BydHal.STATISTIC, ctx, BydHal.systemBypassContext()) ?: return null
            return HalSpeedSignPort(BydHal, id, dev)
        }
    }
}

Wire vào NavigationSpeedSignOwner

// NavigationSpeedSignOwner constructor thay đổi:
private val clusterPort: SpeedSignPort = HalSpeedSignPort.createOrNull(appContext)
    ?: NoopSpeedSignPort(SpeedSignOutput.CLUSTER)  // graceful fallback
