D9 — Letterbox fix (R21)

Root cause

SimpleCastModels.kt defines NORMAL_DEFAULT = DisplayConfig(wmSize = "1920x800", ...). The cluster physical display is 1920×720. When Android fits a 1920×800 logical surface into 1920×720 physical pixels, it preserves aspect ratio by scaling down: 720/800 = 0.9. Result: content renders at 1728×720 → 96px black letterbox each side.

Fix

Change wmSize to "1920x720" — matching display physical dimensions exactly. This eliminates scaling and letterboxing. The existing bounds = CastBounds(0, 90, 1920, 630) continues to work: am task resize operates within the logical surface to carve out OEM bars top/bottom, independent of display scaling.

// Before
val NORMAL_DEFAULT = DisplayConfig(
  wmSize = "1920x800",
  overscan = "0,0,0,0",
  bounds = CastBounds(0, 90, 1920, 630)
)

// After
val NORMAL_DEFAULT = DisplayConfig(
  wmSize = "1920x720",
  overscan = "0,0,0,0",
  bounds = CastBounds(0, 90, 1920, 630)
)
Impact: Only affects AppType.NORMAL. CarPlay (1422×800) and Android Auto (1920×1080) are unaffected — they have their own measured configs. Existing per-app saved configs in user prefs also unaffected (they override NORMAL_DEFAULT).
