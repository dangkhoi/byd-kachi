Global row/result foreign keys: every nonnull rowId resolves one frozen SessionRow; event.rowKind equals row.kind. INVALIDATED is the sole rowless candidate exception. Whenever a row branch carries candidateRevisionId/resultIdentityId, each exactly equals the row property including null. PRECONDITION/DISCOVERY_ONLY probeId equals the READ_ONLY row probe; Freeze.allowedProbeIds equals the sorted-unique READ_ONLY probes. MUTATION operation/outcome binds the row operation. OBSERVATION and terminal observations equal row.observations. CLEAR evidence operation equals row.clear; RESTORE evidence operations equal row.inverse order. A MUTATION PASS requires the preceding CLEAR/RESTORE outcomes PASS and byte-equal evidence; FAIL/INCONCLUSIVE still require restore PASS; restore FAIL permits only BLOCKED/restore.

Per-row contiguous automata: after SESSION_START, rows execute in frozen order and all events for one row are contiguous—no row interleaving. Dependency BLOCKED, SKIPPED or PRUNED is the sole event for a never-started row. Otherwise PRECONDITION is exactly once. FAIL is followed immediately and bidirectionally by BLOCKED/precondition. PASS is mandatory before any later event. READ_ONLY then has zero-or-more DISCOVERY_ONLY events and one terminal PASS|FAIL|INCONCLUSIVE. MILESTONE has exactly one OBSERVATION then one terminal. MUTATION has exactly one MUTATION, one OBSERVATION, one CLEAR, one RESTORE, then one normal terminal; mutation/clear FAIL may yield terminal FAIL only after RESTORE PASS, while RESTORE FAIL is followed immediately/bidirectionally by BLOCKED/restore. Duplicate, missing, out-of-order or interleaved phase events reject. Every event.sessionId equals Freeze.sessionId and SESSION_START.sessionId; the deterministic VehicleSessionPlanRoot template has no sessionId.

Scheduler precedence at each frozen row turn: (1) if an earlier PASS marked the row pruned, emit its sole PRUNED now; prune marking may target non-adjacent rows but emits no out-of-order event; (2) else if truncation is active, emit SKIPPED; (3) else if the first dependency in dependsOnRowIds with terminal not PASS exists, emit dependency BLOCKED; (4) else sample the monotonic clock for budget; nonfit enters truncation and emits SKIPPED, fit begins PRECONDITION. This precedence is exclusive and frozen. A PASS records prune marks for its forward-forest closure; marks are consumed only when each target’s turn arrives.

INVALIDATED quarantine: this branch is exempt from row foreign keys. candidateRevisionId resolves a frozen CandidateRevision. proposedTombstone is a complete closed CandidateRevision object; its ID equals tombstoneRevisionId, is exactly next same-base revision, predecessorCandidateSha256 equals target revisionSha256, CandidateState=REJECTED and invalidationReasonId is in target.invalidatesOn. The proposal is not resolvable in current registry and never changes current Freeze/state/execution. INVALIDATED events form an optional review tail only after every frozen row has one terminal; at most one per target candidate, sorted by parsed candidate ID, with no interleaving.
