Context

Current verdict: v1.02 is not a trusted candidate. The ignored APK hash 69f21744…508d predates current instrumentation; only emulator is connected; SL6 split is full/full; HUD road and speed-sign clear remain unverified on Seal.

What is proven

  • SL6 and Seal full Cast reach the physical cluster.
  • VietMap widget IDs 19/20 are bound and fresh on SL6.
  • Emulator background update, stale clearing and process restore pass.
  • Navigation typed coordinator/store and first-level lane/HUD worker isolation tests pass.
  • Dead Reckon/mock-location product wiring is retired.

What is broken

  • CP/AA may inherit a freeform stack that source says can crash SurfaceFlinger.
  • Cast commits optimistic state after failed landing/resize/return.
  • Arrow and ETA are lost at the Navigation boundary.
  • HUD and speed-sign share an unbounded hidden executor.
  • Two widget providers collapse into one freshness state.
  • Release is debuggable, can debug-sign silently, and lint is non-gating.

Current verification truth

  • :core:test: 599 tests, 6 fail.
  • :app:testDebugUnitTest: 309 tests, 40 fail.
  • :car-integration:test: 30/30 pass.
  • AAPT/debug compilation pass.
  • Most app failures are stale V2/static contracts, proving the suite no longer represents the shipped runtime.

D2 — Cast operation contract

sealed interface DeviceMutationOutcome {
  data class Verified(val evidence: DevicePostcondition) : DeviceMutationOutcome
  data class Rejected(val reason: MutationRejectReason) : DeviceMutationOutcome
  data class Unknown(val command: String, val reason: String) : DeviceMutationOutcome
  data class TimedOut(val command: String, val elapsedMs: Long) : DeviceMutationOutcome
}

// No state/pref commit occurs outside Verified.

Protected target rule

CP/AA classification is produced by one policy, carried as a closed type and rechecked by placement. Destination stack must be standard + fullscreen on the selected display. If not proven, return Rejected(PROTECTED_FULLSCREEN_STACK_UNPROVEN); never guess.

Queue rule

Capacity is bounded. One active operation plus at most one replaceable latest Cast target; Stop/Close is never queued behind unbounded work. Timeout closes the dadb session and records evidence ID, command, elapsed time and outcome.
