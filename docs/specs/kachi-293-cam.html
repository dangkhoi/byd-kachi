Chức năng

4.2 Ai được hiện — luật sự kiện mới nhất thắng + toggle theo thứ ĐANG HIỆN

shown(blinker, demand, demandNewer) = if (demandNewer) demand ?: blinker else blinker ?: demand
next(current, Toggle(w), visible)   = if (current == w && visible == w) null else w      // nút · câu MỞ
next(current, Close(w))             = if (current == w) null else current             // câu TẮT
next(current, CloseAll)             = null                                            // «Tắt camera» · «tắt cam»

Bảng ở :core CameraDemand + CameraDemandState (bài CameraDemandTest · CameraDemandStateTest). Controller giữ showing = camera của phiên đang treo (sự thật của cửa sổ) và truyền nó làm visible; MỌI lượt đổi camera (xi-nhan đổi bên · bấm camera khác · xi-nhan chen) đi qua show(next), nơi phiên cũ được dỡ TRƯỚC khi mở phiên mới (cùng chuỗi dỡ có bài canh của 2.75).
